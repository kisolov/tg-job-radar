# Веб-панель tg-job-radar — дизайн

Источник истины по виду — макет `design/web-panel/project/{Main,Findings,Sources}.dc.html`
(локальный превью — `design/web-panel/preview/Main.html`). Спека написана с артбордов.

## Зачем

Бот даёт `/status` одной строкой. Панель показывает то же и больше: что делает каждый парсер
(аккаунт), как сообщения проходят конвейер за сутки, все находки с решением LLM и полный список
источников. Только для владельца.

## Экраны (как на макете)

**Обзор** (`#/`): KPI за сутки UTC (прочитано, предфильтр, уникальных + склеено копий, ушло в LLM
+ пакетов, доставлено + ждут отправки, стоимость LLM + токены); воронка «Конвейер за сутки»
(прочитано → предфильтр → уникальных → классифицировано → подошло → доставлено); таблица
«Парсеры» (телефон с маской, статус, групп / лимит, вступлений сегодня / дневной лимит, темп
= множитель интервала, каналов на опросе, последнее событие); столбцы «Находки за 7 дней»
(доставлено по дням); блок LLM (модель, токены из лимита, запросов, пакет/ожидание, ждут
классификации); 4 последние доставленные находки; сводка источников. Шапка: статус доставки,
кнопка паузы/возобновления, время обновления. Автообновление раз в 30 с.

**Находки** (`#/findings`, `#/findings/<id>`): поиск по тексту, вкладки решения
(Все / Доставлены / В очереди / Ждут LLM / Отклонены) со счётчиками, тип (все / вакансии /
проекты), период (сегодня / 7 / 30 дней). Список по 20, «Показать ещё». Справа — выбранная
находка: тип, статус, версия требований, заголовок (summary LLM, иначе первая строка текста),
деньги, формат, контакт, почему подходит/отклонена, оригинал, текст, «Встречалось также в».

**Источники** (`#/sources`): добавление ссылками (как `/add`), счётчики по статусам, вкладки
(Все / Читаются / Ждут / Мёртвые / Отсеяны), тип, сортировка (по находкам / по прочитанному /
новые), таблица по 20 со страницами, удаление (как `/remove`).

Статус источника на экране: `active` и (канал или вступили) → «Читается»; `active`, группа,
не вступили → «Ждёт вступления»; `candidate`/`resolving` → «Ждёт резолва»; `dead` → «Мёртвый»;
`rejected` → «Отсеян». Вкладка «Ждут» = ждут резолва + ждут вступления.

## Решения (мои)

- **Сервер — `aiohttp.web` в том же процессе**, задача `web` рядом с ботом. aiohttp уже
  зависимость; FastAPI ради пяти JSON-ручек — лишний пакет и второй event-loop-стек.
- **Фронт — одна статическая страница без сборки** (`panel/static/`: html + css + js, hash-роутинг).
  Nuxt для трёх экранов одного пользователя не окупается. Вёрстка и токены — с макета.
- **Вход — одноразовая ссылка из бота.** Команда `/web` (только владелец, R11) присылает
  `WEB_BASE_URL/login?t=<токен>`; токен HMAC-подписан, живёт 10 минут, срабатывает один раз.
  `/login` ставит подписанную cookie сессии на 30 дней (HttpOnly, SameSite=Lax, Secure при https).
  Без cookie: `/api/*` → 401, страница показывает «Откройте панель командой /web в боте».
  Изменяющие запросы требуют заголовок `X-Radar: 1` (вместе с SameSite — защита от CSRF).
- **Секрет** — `WEB_SECRET`, пустой → выводится из `USERBOT_STORE_KEY` (sha256).
- **Слушает `WEB_HOST:WEB_PORT`** (по умолчанию `127.0.0.1:8080`); в compose — `0.0.0.0` внутри
  контейнера и проброс `127.0.0.1:8080` наружу. Публиковать в интернет — через reverse-proxy с TLS,
  это вне панели.
- **Чтение — один порт `PanelReadModel`** с SQL-реализацией; правил в нём нет, только выборки.
  Фейка нет: выборки тестируются на настоящем Postgres (db-test). Запись идёт через уже
  существующие usecase'ы (`AddSource`, `SetPaused`) и `SourceService.remove`.
- **«Последнее событие» парсера** — `last_error` аккаунта (журнала событий нет). Пусто → «—».
- **Время** — сервер отдаёт ISO UTC, браузер показывает локальное; сутки KPI — UTC, как `daily_stats`.

## Режим без бота (добавлено 2026-11-09)

`BOT_TOKEN` необязателен. Без него: задачи `bot` нет, `notifier` — `PanelOnlyNotifier` (находка сразу `delivered`,
на экране — «Принята»), вход — `POST /login {password}` (`WEB_PASSWORD`, сравнение за постоянное время, пауза 1 с
на неверный), алерты — `AlertLog` (последние 50 в памяти) → блок «Алерты» на «Обзоре»; кнопки паузы нет, в шапке
«Бот выключен — находки только здесь». С ботом алерты идут и в Telegram, и в панель (`TeeAlertSink`).
Настройки: без бота обязательны `WEB_PASSWORD` и `WEB_PORT` ≠ 0; с ботом — `OWNER_TELEGRAM_ID`.
Секрет подписи выводится из `USERBOT_STORE_KEY` (есть в обоих режимах).

## Не цели

Правка требований и `/set` из панели, управление аккаунтами (логин, импорт), графики дольше
7 дней, многопользовательский доступ.
